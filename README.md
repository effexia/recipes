# Recipes

## About

This is a simple multi-page recipe website built as part of The Odin Project's Foundations course. The site displays a homepage listing several recipes, each linking to its own dedicated page with an image, description, ingredients, and step-by-step instructions.

## Skills demonstrated

By completing this project, I practiced:

- Writing semantic HTML5 structure and boilerplate
- Creating and linking multiple HTML pages within a project
- Building relative file paths between nested directories
- Using appropriate heading hierarchy and lists (ordered/unordered)
- Sourcing and properly attributing freely licensed images
- Using Git and GitHub for version control (commits per iteration)
